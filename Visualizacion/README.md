# Scientific figure sources (draft)

This folder contains a prototype chart exporter for the Data Wiki's proposed **Measurement, Experiment, and Signal** chapter. It is **not** a new general-purpose plotting library merged into main, and it does not replace the separate optimization visualization facade in `JulTob/Optimization/Wizard/Graphikon`.

## Source of the illustration

- [`figures/thermometer_samples.csv`](figures/thermometer_samples.csv) — three explicitly **invented teaching samples**: 0, 1, and 2 minutes; 20.0, 20.3, and 20.6 °C.
- [`figures/thermometer_signal.svg`](figures/thermometer_signal.svg) — vector plot with markers at the three sample instants.
- [`figures/thermometer_signal.mmd`](figures/thermometer_signal.mmd) — optional Mermaid XY line source (only visual interpolation).
- [`figures/thermometer_signal.json`](figures/thermometer_signal.json) — transparent source metadata.
- [`scientific_figures.py`](scientific_figures.py) — reusable source-to-figure exporter for sampled signals and calculated histograms.
- [`tests/test_scientific_figures.py`](tests/test_scientific_figures.py) — three initial pytest checks for exact samples, bin conservation and invalid inputs.

## Reproduce

Install Python 3.10+ with `matplotlib`, `numpy` and (for tests) `pytest`.

```bash
python Visualizacion/scientific_figures.py signal \
  --csv Visualizacion/figures/thermometer_samples.csv \
  --x-column minute --y-column temperature_c \
  --x-unit min --y-unit '°C' \
  --x-label Time --y-label 'Room temperature' \
  --title 'Measured room temperature (illustrative)' \
  --output /tmp/thermometer_signal

pytest -q Visualizacion/tests/test_scientific_figures.py
```

Plots exported by the script are not automatically uploaded to the Wiki. The Wiki is read-only to agents, and figures are placed only after the author checks and merges them.

## Rendering selection

- **Mermaid XY:** quick small bar/line charts, provided the actual target GitHub Wiki renders that syntax. Mermaid does not natively compute a histogram from samples. For a discrete signal, a connecting line must not be described as observed continuous values.
- **SVG/PNG:** scientific figures with accurate numerical bins, irregular axes, markers, or error bars; source, units and caption required. SVG is stored here; PNG is generated by the same code.
- **True histogram:** choose numerical bins and normalization, calculate counts or density, and verify total count = sample size (or density integrates appropriately). Three points are an inadequate empirical sample for characterizing a distribution.
